# SandiStay - Sistema de Gestión Hotelera 🏨

Plataforma web integral para la gestión de reservas de habitaciones y áreas sociales. 

## 🛠 Stack Tecnológico
* **Backend:** Java 25, Spring Boot 3, Gradle.
* **Frontend:** Svelte 5, SvelteKit, Tailwind CSS 4.
* **Base de Datos:** PostgreSQL 17.
* **Infraestructura:** Docker & Docker Compose.

## 📂 Estructura del Proyecto (Monorepo)
* `/Documentation_Methodology`: Documentación de ingeniería (V-Model).
* `/SQL_Files`: Scripts de base de datos (DDL, Vistas, Funciones).
* `/backend`: API REST (Próximamente).
* `/frontend`: Aplicación Web (Próximamente).
